    色

    • モデルの出力のまま
    • 人が追加・修正した音
    • 楽譜の提案で足した音
    • 受け入れた候補
    • 見落としの候補(未確認)

    濃さはベロシティ。背景の青はモデルが「鳴っている」と判断した度合い。上の帯は録音の波形。

    操作

    • スペース 再生 / 停止(目盛りか波形をクリックした位置から)
    • P 選択した音(違い)の前後を再生
    • J / K 次 / 前の違い
    • A 提案を当てはめる / O 演奏どおり / U 不明
    • クリック 選択 / Shift+クリック 追加選択 / 空いた所をドラッグ 範囲選択
    • ドラッグ 移動(上下で音高) / 右端をドラッグ 長さ
    • 空いた所をダブルクリック 音を追加
    • 候補をダブルクリック or Enter 受け入れる
    • Delete 削除(候補なら却下)
    • ↑↓ 音高 ±1(Shift で ±12) / ←→ 時刻 ±10ms
    • R 選択した音を再調整 / Shift+R 修正した音をすべて
    • 楽譜の小節をクリック その時刻へ移る
    • ホイール 上下 / Shift+ホイール 左右 / Ctrl/⌘+ホイール 拡大縮小
    • 左の鍵盤をクリック その音を鳴らす
    録音(WAV)を読み込むか、プロジェクトを開いてください。
