操作

  • スペース 再生 / 停止(上の目盛りをクリックした位置から)
  • P 選択した音の前後を再生
  • クリック 選択 / Shift+クリック 追加選択 / 空いた所をドラッグ 範囲選択
  • ドラッグ 移動(上下で音高) / 右端をドラッグ 長さ
  • 空いた所をダブルクリック 音を追加
  • 候補をダブルクリック or Enter 受け入れる
  • Delete 削除(候補なら却下)
  • ↑↓ 音高 ±1(Shift で ±12) / ←→ 時刻 ±10ms
  • R 選択した音を再調整 / Shift+R 修正した音をすべて
  • ホイール 上下 / Shift+ホイール 左右 / Ctrl/⌘+ホイール 拡大縮小
  • 左の鍵盤をクリック その音を鳴らす
録音(WAV)を読み込むか、プロジェクトを開いてください。
