# 演奏MIDIと楽譜の対応付けの評価

2026-11-19。`src/performance_analysis/align.py`。PEDB 2nd edition の全100演奏。正解は matchファイル(人手で修正済み)。
再現: `python3 scripts/performance/eval_alignment.py --source midi|kong --split dev|test`、
`python3 scripts/performance/compare_note_tables.py output/note_tables_midi output/note_tables_kong`。

## 方式

1. 楽譜の「同時に鳴る音のまとまり」の並びと、演奏の「ほぼ同時に弾かれた音のかたまり」(発音の間隔 35ms 以内)の並びを、
   音の集合の食い違いを費用として DTW にかける。1つのまとまりが複数のかたまりを吸収すると罰を加える
2. 対応から「楽譜の拍 -> 演奏の時刻」の写像を作る(時刻が戻らない点だけを残し、外れ値を除いて折れ線で補間)
3. 音高ごとに、楽譜音と演奏音を予測時刻の差が小さくなるよう順序を保って1対1に対応させる(動的計画法)。写像を作り直して2回
4. 抜けにした楽譜音を、同じ音高の残りの演奏音から ±1秒で探し直す(低音だけ先に弾く、大きなアルペジオなど)
5. 残りを、装飾(トリル・ターンなど)の音、弾き間違い(±2半音)、余分な音に分ける

前打音・後打音(fmt3x の short-app / after-note)も楽譜音として扱う。共有音(2声部が共有する音)は1つとして扱う。

  「TEST を見た後」の値である。下の表には両方を載せる

## 結果

楽譜音の対応の正解率 = 各楽譜音に対応させた演奏音(なしを含む)が正解と同じ割合

| 入力 | DEV | TEST(最初) | TEST(DTW を直した後) | TEST 演奏ごとの中央値 / 最小 |
|---|---|---|---|---|
| 同時記録MIDI | 99.6% | 97.1% | 99.2% | 99.7% / 84.1% |
| 採譜モデル(Kong)の出力 | 98.7% | 96.6% | 98.6% | 99.1% / 83.8% |

TEST(直した後)の内訳:

| 入力 | 抜けた音の検出 適合率 / 再現率 | 余分な音の検出 適合率 / 再現率 | 装飾の音のラベル |
|---|---|---|---|
| 同時記録MIDI | 0.93 / 0.97 | 0.41 / 0.84 | 79% |
| Kong の出力 | 0.96 / 0.92 | 0.89 / 0.87 | 77% |

- Kong の出力では、Kong が検出しなかった音も「抜け」、Kong の余分な検出も「余分」として正解に含める。
  採譜の誤りの多く(弱い音の検出もれ、再検出・倍音)を、対応付けで正しく「抜け」「余分」と判定できている
- 同時記録MIDIの余分な音の適合率が低いのは、正解の余分な音が少ない(227音)ため。余分と誤判定した約280音の内訳は、
  正解では通常の音 110、装飾の音 100、弾き間違い 68(match の弾き間違いには ±2半音を超えるものもある)
- 装飾の音: match ファイルでは、装飾のどの演奏音を対応状態 0(主)とするかが一定しない(最初の音のことも、2番目の音のこともある)。
  ここは正解の側の決め方にも依存する
- 残っている大きな失敗: chp-pld004-s-p2(84%)

## 全自動の表(録音 -> Kong -> 対応付け -> 表)と、人手の match から作った表の比較(TEST)

| 列 | 相関 | 差の絶対値の中央値 / 90% 点 | 演奏ごとの相関の中央値 |
|---|---|---|---|
| 局所テンポ | 0.999 | 0.06 / 0.48 bpm | 1.000 |
| タイミングのずれ | 0.945 | 2.0 / 8.0 ms | 0.978 |
| 拍のずれ | 0.957 | 1.7 / 6.7 ms | 0.991 |
| 和音内の時間差 | 0.727 | 1.1 / 7.1 ms | 0.868 |
| 強さ(velocity_z) | 0.888 | 0.29 / 0.75 | 0.893 |
| 音の長さの比 | 0.337 | 0.70 / 2.49 | 0.394 |

楽譜音の状態(ok / missing など)の一致は 96.0%。同時記録MIDIを自動で対応付けた表では、どの列も相関 0.88 以上
(局所テンポ・強さ・音の長さの比はほぼ 1)で、対応付けによる誤差は小さい。全自動の表の差は主に採譜(Kong)の誤差である。

音の長さの比(アーティキュレーション)は、Kong の離鍵がペダル中は「音が止んだ時刻」になるため使えない
(docs/kong_evaluation.md)。それ以外の列は、全自動でも分析に使える精度である。
